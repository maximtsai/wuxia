# Bundled fonts

Marcellus Regular is used for headings and class names. Noto Sans variable
(weights 100–900) is used for interface text and canvas labels. Both are served
locally; no third-party font stylesheet or runtime font request is required.

Downloaded from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/marcellus
- https://github.com/google/fonts/tree/main/ofl/notosans

Original font files are unmodified. Their SIL Open Font License texts are
included as Marcellus-OFL.txt and NotoSans-OFL.txt.
